# Habi Finance Dashboard

Encrypted dashboard — opens with a password. Served via GitHub Pages.

Published from `Historical_Financials/publish.sh` with `PUBLIC_BUILD=1`, which
folds natural persons in the tercero drill into an aggregated
"Personas naturales (N)" row. Only `index.html` belongs on this remote; the
dated copies under `archive/` and the board variant stay on the local machine
(see `.gitignore`).
